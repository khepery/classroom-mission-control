CLASSROOM MISSION CONTROL. EXTRA ASSET PROMPTS FOR GPT IMAGES

How to use
Paste the STYLE line of each section in front of every prompt in that section.
Sizes: square 1024x1024, wide 1536x1024, tall 1024x1536. Each prompt says which one.
Ask for no text in every image. I add all words in the app so they stay sharp and can be translated.
Make 2 or 3 from a section first and send them to me before doing the whole set.
Name each file as shown in brackets, for example vs-read.png.
