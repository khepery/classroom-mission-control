CLASSROOM MISSION CONTROL - ICON PROMPTS

How to use
1. Paste the STYLE text at the end of every prompt, so all icons match.
2. Square 1:1, 1024x1024. One icon per image.
3. Make 4 or 5 first, check they look like one set, then do the rest.
4. Send them back named by tool, for example timer.png. I will crop, shrink and put them in.

STYLE (add to every prompt)
Square 1:1 app icon, one bold 3D object in the centre filling about 70 percent of the frame, glossy stylised illustration like a premium mobile game icon, soft rim light and a small glow, subtle retro space-age details, simple smooth gradient background in the colour given, no text, no letters, no numbers, no border, no frame, no shadow box
