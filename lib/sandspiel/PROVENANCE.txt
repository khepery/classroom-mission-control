Sandspiel Copyright (c) 2018 Max Bittker, MIT; full license in LICENSE.
wasm/sandtable_bg.wasm was compiled from the unmodified upstream Rust
cellular simulation using Rust 1.99.0,
the wasm32-unknown-unknown target and wasm-bindgen CLI 0.2.129.
The binary is not a replacement or reimplementation of the simulator.

engine.js bundles the upstream js/render.js, js/fluid.js, js/fluidShaders.js
and js/glsl WebGL particle renderer and fluid solver. The fluid solver's
MIT notice for Pavel Dobryakov (2017) is in licenses/fluid.txt. Local adaptations:
pass WASM memory/canvases explicitly, omit the dat.gui developer panel and
upstream mouse/touch/global-UI hooks, expose disposal, delete completed GPU
fences, and export only the particle renderer. A small local engine adapter
exposes bounded painting, ticking, clearing and disposal to our own UI, and
initializes/resets wind bytes to neutral to avoid stale or uninitialized wind.

Only these engine modules are bundled. No Firebase, Sentry, advertisements,
accounts, gallery, publishing, remote assets or service workers are included.
At runtime only engine.js and wasm/sandtable_bg.wasm are required.
The tool is served by the existing local server and needs no Internet access.
The CSP permits local regl's JavaScript command compilation (unsafe-eval);
it still limits scripts and connections to same-origin resources.

Build record:
- cargo build --locked --release --target wasm32-unknown-unknown against the
  downloaded upstream crate; rustup provided the wasm32 standard library.
- wasm-bindgen CLI 0.2.129, --target web --out-name sandtable.
- esbuild 0.28.2 and glslify 7.1.1 bundled the adapted upstream WebGL modules,
  generated WASM glue and the small local adapter as ESM.
- Resolved direct Rust versions: cfg-if 0.1.10, wasm-bindgen 0.2.129,
  js-sys/web-sys 0.3.106, rand 0.8.8, rand_xoshiro 0.6.0,
  console_error_panic_hook 0.1.7 and getrandom 0.2.17.

Build tools, manifests, downloaded source and temporary files were removed
after verification. The distribution contains production assets and notices
only; no project-root build configurations were added.
